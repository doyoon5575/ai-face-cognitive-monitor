# 🧠 AI 다중 생체신호(안면·음성) 컨디션 & 인지 건강 모니터링 시스템

> **Google MediaPipe Tasks (Face Mesh 478 랜드마크 & 52 Blendshapes)** 와 **DeepFace**, **실시간 오디오 마이크 바이오마커**, **두뇌 인지 인터랙티브 평가**가 결합된 차세대 멀티모달 AI 헬스케어 솔루션입니다.  
> 아동, 성인, 직장인, 수험생, 시니어, 재활 환자 등 **누구나 자신의 신체·정서·두뇌 컨디션을 실시간으로 자가진단**할 수 있습니다.

---

## 🌟 핵심 기능

1. **실시간 안면 랜드마크 선 (Face Mesh Wireframe)**
   - 눈 윤곽, 눈썹, 콧날, 입술 윤곽, 턱선을 따라 미래지향적 네온 랜드마크 선 실시간 오버레이
2. **미세 표정 바이오마커 3종**
   - **입술 활력도 (Mouth Dynamics)**: 미소, 입꼬리 대칭, 입술 삐죽거림, 개구도 실시간 측정
   - **눈가 피로도 (Eye Fatigue)**: 깜빡임 빈도, 미간 찌푸림, 눈 피로 지수
   - **안면 대칭도 (Facial Symmetry)**: 좌우 표정 근육의 균형 지수
3. **마이크 실시간 음성 바이오마커 (Voice Vitality)**
   - 발화 시 실시간 음성 성량(RMS, dB) 및 목소리 톤 활력도 측정
4. **동시 진행 일체형 듀얼 스크린 UI**
   - **좌측**: 실시간 다중 생체신호(안면+음성) 피드
   - **우측**: 실시간 두뇌 인지 & 컨디션 퀴즈 (문제를 풀면서 얼굴과 목소리를 동시에 실시간 관찰)
5. **종합 다차원 컨디션 성적표**
   - [인지 퀴즈 점수] + [얼굴 미세 피로도] + [목소리 활력도]를 종합 분석한 맞춤형 생활 가이드

## 🚀 실행 방법

### 1. 로컬(내 컴퓨터) 실행
폴더 내의 **`실시간_표정거울_실행.bat`** 파일을 더블 클릭하면 내 브라우저(`http://localhost:8501`)가 열립니다.

### 2. 스마트폰 및 외부 기기 접속 실행 (추천 📱)
폴더 내의 **`외부접속_표정거울_실행.bat`** 파일을 더블 클릭하면:
1. 로컬 서버와 초고속 보안 Cloudflare 터널이 자동 실행됩니다.
2. 터미널 창에 발급된 **`https://xxxx.trycloudflare.com`** 전용 보안 링크가 표시됩니다.
3. 스마트폰이나 외부 PC 브라우저에 해당 링크를 입력하면 전 세계 어디서든 대시보드에 즉시 접속할 수 있습니다.

### 터미널 수동 실행
```bash
# 로컬 전용 실행
python -m streamlit run senior_app.py --server.port 8501

# 외부 터널 동시 실행
python run_tunnel.py
```

├── database/

└── 외부접속_표정거울_실행.bat     # 외부 접속 전용 원클릭 실행 스크립트 (스마트폰 연동)
